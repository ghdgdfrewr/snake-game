🐍 Snake Game — Single Player

🎮 A simple, modern Snake game built with HTML5 Canvas + JavaScript.
Play directly in your browser — no downloads needed!

🔗 Play Online

Once deployed on GitHub Pages, visit:
👉 https://ghdgdfrewr.github.io/snake-game/

🕹️ How to Play

Move: Arrow keys ← ↑ → ↓ or WASD

Pause / Resume: Spacebar

Restart: R key

Mobile: Use on-screen arrows or swipe gestures

Avoid hitting yourself — eat the 🍏 green apples to grow your snake and increase your score!

⚙️ Features

✅ Clean, responsive UI (works on desktop and mobile)
✅ Dynamic grid sizes (Small / Normal / Large)
✅ Adjustable game speed as score increases
✅ Local high score saved in browser
✅ Single-file, no dependencies — perfect for GitHub Pages
